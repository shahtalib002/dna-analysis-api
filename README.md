# Ancient DNA Analysis API

## Description

This project implements a FastAPI server designed to assist an Advanced Forensic Research Team in analyzing ancient DNA sequences. The goal is to uncover connections between ancient populations based on genetic similarities derived from historical data.

The server handles potentially incomplete data about ancient remains (region, age, DNA seed), uses a provided costly function to generate DNA sequences from this data, compares sequences for similarity, and provides a natural language interface for user queries about the API itself.

This project fulfills the requirements of the ML-AI Intern Assignment.

## Features & API Endpoints

The FastAPI server provides the following functionalities:

* **Data Upload & Cleaning:** Handles upload of potentially incomplete CSV data for ancient remains.
* **DNA Sequence Generation:** Generates DNA sequences using sample details and a seed value, incorporating caching for efficiency due to the costly nature of the generation function.
* **DNA Sequence Comparison:** Compares two generated DNA sequences using the Jaccard Index on 4-mers to calculate a similarity score.
* **Natural Language Queries:** Uses Google Gemini (via Google AI Studio API key) to answer questions about the API's capabilities.

### API Endpoints:

* **`GET /`**
    * **Description:** Root endpoint providing a basic welcome message.
    * **Response:** `{"message": "Welcome to the Ancient DNA Analysis API!"}`

* **`POST /upload-csv/`**
    * **Description:** Uploads a CSV file containing ancient remains data (columns required: `id`, `region`, `age`, `seed`). Cleans the data (handles missing/invalid values) and stores it for use by other endpoints. Overwrites any previously uploaded data and clears the sequence cache.
    * **Request:** `multipart/form-data` with the CSV file.
    * **Response:** `{"message": "File '...' uploaded successfully.", "records_loaded": N}` or an error message.

* **`GET /generate-sequence/`**
    * **Description:** Generates (or retrieves from cache) the DNA sequence for a specified sample ID. Requires data to be uploaded first.
    * **Query Parameter:** `id` (string, e.g., `id_0001`)
    * **Response:** `{"id": "...", "sequence": "..."}` or an error message (404, 400, 409, 500).

* **`GET /compare-sequences/`**
    * **Description:** Compares the DNA sequences of two specified sample IDs and returns a similarity score (0.0 to 1.0). Requires data to be uploaded first. Uses cached sequences if available.
    * **Query Parameters:** `id1` (string), `id2` (string)
    * **Response:** `{"id1": "...", "id2": "...", "similarity_score": float}` or an error message.

* **`POST /ask-me-anything/`**
    * **Description:** Accepts a natural language query about the API and returns an answer generated by an LLM (Google Gemini). Requires `GOOGLE_API_KEY` to be configured.
    * **Request Body (JSON):** `{"query": "Your question here"}`
    * **Response:** `{"response": "LLM generated answer..."}` or an error message (503, 500).

## Setup Instructions

Follow these steps to set up the project locally:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/shahtalib002/dna-analysis-api.git](https://github.com/shahtalib002/dna-analysis-api.git)
    cd dna-analysis-api
    ```

2.  **Create and Activate Virtual Environment:**
    It's highly recommended to use a virtual environment to manage dependencies.
    ```bash
    # Create the virtual environment (e.g., named 'venv')
    python -m venv venv

    # Activate the virtual environment:
    # On Windows (Git Bash or CMD/PowerShell):
    source venv/Scripts/activate
    # On macOS/Linux:
    source venv/bin/activate
    ```

3.  **Install Dependencies:**
    Install all required Python packages using the `requirements.txt` file.
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set Up Environment Variables:**
    The application requires a Google API key for the `/ask-me-anything` endpoint.
    * Create a file named `.env` in the root directory of the project.
    * Obtain an API key from [Google AI Studio](https://aistudio.google.com/).
    * Add the following line to the `.env` file, replacing the placeholder with your actual key:
        ```dotenv
        # .env
        GOOGLE_API_KEY=YOUR_ACTUAL_API_KEY_HERE
        ```
    * **Note:** Ensure the `.env` file is included in your `.gitignore` file and is not committed to version control.

## Running the Server

Once the setup is complete, you can run the FastAPI server using Uvicorn:

1.  Ensure your virtual environment is activated.
2.  Make sure you are in the project's root directory (`dna-analysis-api`).
3.  Run the following command:
    ```bash
    uvicorn main:app --reload
    ```
    * `main:app` tells Uvicorn to find the `app` object (your `FastAPI()` instance) within the `main.py` file.
    * `--reload` enables auto-reloading, so the server restarts automatically when you save code changes (useful for development).

4.  The server should now be running locally at `http://127.0.0.1:8000`.

## Explanation of Logic

### DNA Sequence Generation (`sequence_utils.generate_dna_sequence`)

* The DNA sequence generation is based on the provided `func.py` (now implemented in `sequence_utils.py`).
* The process is **deterministic** based on the input `id` (integer part), `region` (string), and `age` (integer), as these values are used to seed the `random` number generator (`random.seed(f"{id}+{region}+{age}")`). This ensures the same inputs always produce the same sequence of random choices during generation.
* The `dna_seed` string provided in the input data is crucial. The function extracts specific 4-character motifs (like `agtc`, `gcta`, etc., defined internally) from this `dna_seed`.
* If no valid motifs are found within the `dna_seed`, the generation process cannot proceed, and the function returns `"x"`, which the API handles as a "Bad Request" error.
* The generation function includes a computationally **expensive `core()` sub-function**, making the overall process potentially slow for uncached IDs. The API implements an in-memory cache (`sequence_cache`) to store generated sequences and improve performance for repeated requests for the same ID.

### DNA Sequence Comparison (`sequence_utils.compare_sequences`)

* Sequence similarity is calculated using the **Jaccard Index** applied to the sets of **k-mers** (substrings of a fixed length `k`) extracted from the two sequences.
* This implementation uses **`k=4`** (4-mers), aligning with the 4-character motif structure used in the generation process.
* The Jaccard Index is calculated as:
    ```
    Similarity = (Number of unique 4-mers common to both sequences) / (Total number of unique 4-mers present in either sequence)
    ```
    Mathematically: $J(A, B) = \frac{|A \cap B|}{|A \cup B|}$, where A and B are the sets of 4-mers from sequence 1 and sequence 2, respectively.
* The resulting similarity score is a float between **0.0** (meaning the sequences share no common 4-mers) and **1.0** (meaning they contain the exact same set of unique 4-mers).
